# Paulina Loera — Landing Page

Official landing page for Paulina Loera.

Built with Astro, featuring responsive layouts,
bilingual content (English and Spanish), and
an editorial visual design.

## Technologies

- Astro
- HTML
- CSS
- TypeScript

## Local development

Install dependencies:

npm install

Start development server:

npm run dev

Build production website:

npm run build

Preview production build:

npm run preview

## Deployment

Deployed automatically to GitHub Pages
using GitHub Actions.

Website:
https://marivfa.github.io/paulina-landing/
